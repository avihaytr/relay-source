# Installing the preview candidate

These are local candidate instructions, not an announcement of downloadable releases.

## Fedora Linux

The qualified target is Fedora 43, x86_64, GNOME/Wayland with a Vulkan-capable driver and a working ScreenCast portal. Other Fedora versions, architectures and desktop backends are not supported by this first candidate's test matrix. Install the appropriate trusted RPM Fusion Free repository if you choose to use its FFmpeg/x264 packages; the package does not bundle native libraries or configure external repositories automatically.

After checking SHA256SUMS, install the local candidate with:

```sh
sudo dnf install ./relay-0.1.0~alpha.1-1.fc43.x86_64.rpm
relay --connect-phone
```

RPM uses `~alpha.1` for prerelease version ordering; the application/source version is `0.1.0-alpha.1`. Required system libraries/plugins are declared and ELF dependencies are generated by RPM. Advanced ADB/scrcpy mode uses separately installed optional tools. Nearby discovery requires Avahi and a reachable local network. PC-to-phone sharing additionally requires your desktop's screen/window portal and explicit permission; permission prompts must never be bypassed.

Settings use `$XDG_CONFIG_HOME/relay/settings.json` (fallback `$HOME/.config/relay/settings.json`). Default captures use `$XDG_DATA_HOME/relay/captures` (fallback `$HOME/.local/share/relay/captures`). Existing identity/trust files keep their existing location; this preview does not migrate or silently import settings from a private source checkout. Never run the GUI as root.

Uninstall with `sudo dnf remove relay`. User settings, identities, trust and captures are not automatically erased.

## Android

Verify SHA256SUMS and the documented signing-certificate fingerprint before installing the APK. Normal companion sharing needs no developer mode. USB installation for testing is `adb install -r relay-0.1.0-alpha.1-android.apk`; a different signer without an approved rotation lineage cannot update an existing package.

Package identity is `app.relay.companion`, versionCode 1 / versionName 0.1.0-alpha.1; minSdk 26, targetSdk 35, debuggable false. Device playback-audio capture requires Android 10+ and an app permitting capture. MediaProjection consent is always required for phone capture. The candidate is signed with a separate encrypted release key and a rotation proof from the earlier local development signer. Modern Android can preserve installed app data on upgrade; behavior on older Android versions is not established by the Samsung test alone.

Do not uninstall the owner's existing app merely to test a clean installation: that destroys its local pairing state. Use the isolated emulator or a dedicated device. Local development builds are not a substitute for the release-signing process. See ANDROID_SIGNING.md for key custody and recovery requirements.
